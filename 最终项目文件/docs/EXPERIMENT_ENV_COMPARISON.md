# 实验环境与对比分析方案说明

本文档详细标注了项目中生成的各项可视化对比图表（`results_plots/`）对应的具体实验环境、采用的均衡方法及解调方式，以便于对照验证实验的严谨性与创新点的有效性。

---

## 1. Fig1_SNR_vs_BER_Comparison (信噪比-误码率对数对比曲线图)

**全局实验环境**：多途多普勒移动水声信道（含海浪波动及 AR(1) 湍流扰动，10000次蒙特卡洛抽样）

*   **第一条曲线（传统差分相关解调 - 蓝色方块虚线）**
    *   **信道名称**：多途多普勒移动水声信道
    *   **均衡方法**：无或单边均衡
    *   **解调方式**：差分相关解调 (`diff_corr_decode`)
*   **第二条曲线（传统差分能量解调 - 绿色三角点划线）**
    *   **信道名称**：多途多普勒移动水声信道
    *   **均衡方法**：无或单边均衡
    *   **解调方式**：差分能量解调 (`diff_energy_decode`)
*   **第三条曲线（改进差分能量解调 - 青色菱形虚线）**
    *   **信道名称**：多途多普勒移动水声信道
    *   **均衡方法**：无或单边均衡
    *   **解调方式**：改进型差分能量解调 (`gaijin_diff_energy_decode`)
*   **第四条曲线（传统卡尔曼时延锁相解调 - 品红叉号点划线）**
    *   **信道名称**：多途多普勒移动水声信道
    *   **均衡方法**：传统固参卡尔曼追踪锁相 (Standard KF)
    *   **解调方式**：基于传统卡尔曼滤波的差分解调
*   **第五条曲线（【创新点】方法 - 红色五角星粗实线）**
    *   **信道名称**：多途多普勒移动水声信道
    *   **均衡方法**：TRM 时间反转镜盲估计预聚焦 + 自适应新息协方差卡尔曼时延锁相环 (IAKF-DLL)
    *   **解调方式**：判决反馈残差相漂自适应校准块解调 (`block_doppler_decode_silent`)

## 2. Fig2_Constellation_Diagram_Comparison (解扩符号复星座图凝聚度对比)

**全局实验环境**：极恶劣海洋多径拓展信道（包含强多普勒相移和多径拉扯效应）

*   **左侧图表（传统解调符号样本）**
    *   **信道名称**：极恶劣海洋多径拓展信道
    *   **均衡方法**：无
    *   **解调方式**：传统无相偏校准解调
*   **右侧图表（【创新点】校准凝聚样本）**
    *   **信道名称**：极恶劣海洋多径拓展信道
    *   **均衡方法**：TRM 时间反转镜预聚焦 + DF-IAKF 联合均衡
    *   **解调方式**：自适应相漂补偿块解调

---

## 3. Fig3_Tracking_Error_Trajectory_Comparison (海浪突变下动态时延追踪误差轨迹图)

**全局实验环境**：动态海浪加速度突变多普勒信道（存在瞬态加速度峰值扰动）

*   **第一条曲线（传统固定卡尔曼锁相 - 黑色点划线）**
    *   **信道名称**：海浪突变多普勒水声信道
    *   **追踪均衡方法**：传统固定参数卡尔曼滤波锁相环 (Standard KF)
    *   **表现特征**：在多普勒加速度突变点容易发生滞后甚至严重发散脱锁
*   **第二条曲线（【创新点】自适应新息卡尔曼 - 红色粗实线）**
    *   **信道名称**：海浪突变多普勒水声信道
    *   **追踪均衡方法**：基于自适应新息匹配的卡尔曼时延锁相环 (IAKF-DLL)
    *   **表现特征**：瞬态响应快，追踪误差极小，始终紧密对齐 0 误差刻度

---

## 4. Fig4_Complexity_vs_Performance_BarChart (算法复杂度与运行时间柱状图对比)

**全局实验环境**：标准通信帧数据单次解调测试

*   **左侧 Y 轴（算法运行耗时）**
    *   测量并对比了传统基础解调算法与【创新点】系统级算法处理单帧数据所需的毫秒级 (ms) 时间开销。
*   **右侧 Y 轴（误码率增益倍数）**
    *   衡量在极低信噪比恶劣工况下，引入【创新点】算法带来的误码率降低数量级或增益倍数，凸显牺牲极少计算量换取高可靠性的性价比。
